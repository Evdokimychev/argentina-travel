Тех-задание для исполнения и **визуальной приёмки в dev** (в песочнице агента `next build`/`tsc`/`vitest` не запускаются — несовместимые бинарники, поэтому визуальная часть выносится сюда). Дата: 2026-07-06.

## 2. Канонические токены (использовать только их)

Палитра (`src/styles/tokens.css`, Tailwind-классы через `@theme`): `sky` (#74ACDF, основной/CTA/ссылки), `sky-ink` (текст-акцент), `sun` (#FCBF49, рейтинг/звёзды), `patagonia` (#2D4A3E), `wine` (#722F37), `sand`/`surface-muted`/`surface-elevated`, `charcoal`/`foreground` (текст), `slate`/`muted` (вторичный текст), `border-default`/`border-subtle`.

Семантические классы: `rounded-card`, `shadow-card`, `bg-surface-elevated`, `text-foreground`, `text-charcoal`, `sky-ink`.

**Правило:** ни одного нового HEX в компонентах — только классы/переменные токенов. В SVG использовать `fill="var(--token-color-sky)"` и т. п.

## 3. Единая карточка (базовый компонент `ContentCard`)

Ввести один компонент-обёртку и перевести на него карточки «Места», «Регионы», «Карта»-поповер, блог, база знаний:

```
рамка:      border border-border-subtle
фон:        bg-surface-elevated
скругление: rounded-card            (canonical; = 1rem/16px — согласовать один раз)
тень:       shadow-card             (hover: чуть усилить)
паддинг:    p-4 (мобайл) / p-5 (десктоп)
обложка:    aspect-[4/3], object-cover, rounded сверху
заголовок:  font-heading text-base font-bold text-charcoal, 2 строки максимум (line-clamp-2)
описание:   text-sm text-slate, line-clamp-2/3
бейдж:      категория/регион — pill: bg-sky/10 text-sky-ink text-xs rounded-full px-2 py-0.5
рейтинг:    звёзды цветом sun
CTA:        «Подробнее» + вторичная ссылка «В базе знаний →» (kbSlug/href в базе)
```

Приоритет: заменить дублирующую вёрстку в `PlaceCard`, `MapObjectCard`, destination-карточках и `KbEntryCard` на `ContentCard` с вариантами (`variant="place|region|article|map"`).

## 4. «Места» (`/places`) — редизайн

- **Сетка:** `grid gap-4 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4`, карточки `ContentCard variant="place"`.
- **Фильтры** (`MapCategoryFilters`/`places-catalog-filters`): вынести в единую панель-строку сверху (чипы-пиллы категорий с активным состоянием `bg-sky text-white`, неактив — `bg-surface-muted text-charcoal`); регион — выпадающий фильтр; сортировка (популярность/рейтинг/имя). Мобайл — горизонтальный скролл чипов + «Фильтры» в bottom-sheet.
- **Поиск:** единый компонент (см. §6), инстант-фильтрация по name/tags/region (данные из базы).
- **Карта↔список:** переключатель «Список | Карта»; при наведении на карточку — подсветка пина, при клике на пин — та же `ContentCard` в поповере. Карта уже читает те же данные (`/api/map/objects` → `fetchPlacesServer` с наложением базы).
- **Деталь места** (`PlaceDetailView`): описание/сезон/логистика — из базы; галерея (кураторская); ссылка **«Подробный разбор в базе знаний →»** уже выведена. Донор-обложки у 49 новых мест — заменить реальными фото (см. §7).

## 5. «Регионы» (`/destinations`) — редизайн

- 8 хабов, сгруппированы по `regionGroup` (6 групп). Заголовок группы + сетка хаб-карточек `ContentCard variant="region"` с крупной обложкой, названием, коротким интро (из базы), «лучший сезон» и «длительность» (из базы).
- Деталь направления (`DestinationDetailView`): интро/сезон/логистика — из базы (уже наложено); блоки «Главное» и «Советы» — кураторские; добавить связанные «Места» региона (из базы по `region_id`) и ссылку в соответствующий раздел базы знаний.
- Единый герой-блок с картой-миниатюрой региона (переиспользовать `PodborRegionMap`).

## 6. Сквозная унификация компонентов

- **Кнопки:** один `Button` с вариантами `primary` (`bg-sky text-white hover:bg-sky-dark`), `secondary` (`border border-border-default text-charcoal`), `ghost`. Убрать ad-hoc кнопки.
- **Поиск:** один `SearchBox` (иконка-лупа, `rounded-full`, `border-border-subtle`, focus-ring `sky`) для «Места», «Регионы», база знаний, блог.
- **Чипы/теги:** один `Tag`/`Chip` (pill, `bg-sky/10 text-sky-ink`).
- **Бейдж рейтинга, хлебные крошки, «Читайте также»/«Связанные», пустые состояния** — по одному компоненту, общий стиль.
- **Типографика:** заголовки `font-heading`; шкала h1 `text-3xl`, h2 `text-2xl`, h3 `text-xl`, карточка `text-base`; тело `text-sm/base text-slate`.
- **Отступы:** секции `py-10 md:py-14`, контейнер `siteContainerClass`, карточные сетки `gap-4`.

## 7. Данные/медиа (связь с базой знаний)

- Текст «Мест»/«Регионов»/«Карты» — из базы (менять контент только в базе знаний → пересборка `content/knowledge-base/_index/content.json` → всё обновляется). Не хардкодить тексты в компонентах.
- 49 новых мест и часть регионов используют **донор-обложки** (`PLACE_COVER_FALLBACK_MAP`) — заменить реальными фото (Wikimedia Commons, свободные лицензии) по волнам; до тех пор карточки показывают региональный донор, а не логотип.

## 8. Порядок работ и приёмка (в dev)

1. Согласовать канонический радиус карточек (рекомендация: `rounded-card` = 1rem) и мигрировать `rounded-xl/2xl/lg/3xl` в разделах → `rounded-card` пошагово, с визуальной проверкой.
2. Ввести `ContentCard` и перевести «Места» → «Регионы» → «Карта»-поповер → блог/база.
3. Унифицировать `Button`/`SearchBox`/`Tag`/пустые состояния.
4. Заменить оставшийся хардкод HEX на токены (§1).
5. Заменить донор-обложки реальными фото.
6. **Гейты:** `npm run audit:quick`, `npx tsc --noEmit`, `npx vitest run`, `next build`; затем визуальная проверка каждой страницы (Места список/деталь, Регионы список/деталь, Карта, блог-статья, страница базы знаний) на десктопе и мобайле; проверка светлой/тёмной темы, если есть.
