# Управление контентом

## Ответственность

| Роль | Решение |
| --- | --- |
| Владелец продукта | коммерческие обещания, юридическая модель, финальный go/no-go |
| Главный редактор | тон, структура, canonical, публикационная готовность |
| Редактор направлений | география, места, сезоны, маршруты |
| Редактор переезда | миграция, документы, гражданство |
| Финансовый редактор | деньги, банки, налоги, курсы и цены |
| Фактчекер | item-level связь утверждения с первичным источником |
| Юридический проверяющий | регулируемые утверждения и оговорки; не заменяет профильного юриста |
| Медиа-редактор | соответствие изображения контексту, alt, размеры |
| Владелец медиа-прав | лицензия, автор, источник, юридическое основание |
| SEO-владелец | sitemap, canonical, redirects, индексируемость |
| Operations | production-поиск, внешние кабинеты, мониторинг и cron |

Если человек не назначен, в CSV остаётся функциональная роль и статус `review_required`; имя не придумывается.

## Источник истины

- База знаний: Markdown и сгенерированный индекс `content/knowledge-base/_index/content.json`.
- Публичность базы: только `isPublicKbEntry` и текущий публикационный gate.
- CMS-материалы: опубликованная CMS-версия; TS/seed служит fallback, а не параллельной правдой.
- География: `src/data/geography-canonical.ts` и согласованный глоссарий.
- Редиректы: статические контракты приложения плюс управляемый серверный реестр.
- Медиа: manifest и отдельный аудит прав.
- Партнёрские цена/доступность/checkout: внешний провайдер в момент действия.

## Частота пересмотра

| Тема | Максимальный базовый интервал | Триггер вне графика |
| --- | ---: | --- |
| Миграция, документы, налоги, банки | 45 дней | закон, постановление, изменение процедуры |
| Цена, курс, расписание, тариф | 30 дней или live-источник | изменение API/поставщика |
| Медицина и безопасность | 45 дней | официальное предупреждение |
| Транспорт и связь | 90 дней | новый оператор/тариф/маршрут |
| География и история | 180 дней | исправление источника или таксономии |
| Авторский опыт | 180 дней | смена практической ситуации |

Короткий интервал не заменяет событие: критическое изменение требует немедленной проверки или временного снятия материала.

## Политика публикации

1. Черновик не индексируется и не участвует в рекомендациях.
2. Чувствительный материал без официального источника блокируется.
3. Автоматический перевод не публикуется без русскоязычного редактора.
4. Утверждение без item-level источника получает `review_required`; статья-level список не выдаётся за точное доказательство.
5. Дубликат получает решение KEEP_DISTINCT/MERGE/REDIRECT до публикации.
6. Изображение без проверяемого основания не становится публичным hero.
7. Материал снимается или получает предупреждение, если его актуальность нельзя подтвердить в срок.

## Изменения и аудит

Каждая содержательная правка фиксирует владельца, причину, изменённые факты, источники и новую дату проверки. Массовая механическая нормализация отдельно помечается `facts_changed=no_intentional_fact_change`. После массового изменения пересобираются индекс, CSV-пакет, sitemap и строгий публичный crawl.

Еженедельный контроль: открытые P0/P1, просроченные sensitive, сломанные ссылки, права на новые медиа, search freshness. Ежемесячный: дубли, сироты, тонкие материалы, taxonomy drift и конверсионные страницы.
