# Политика фотографий и медиа

## Статус существующей библиотеки

В `src/data/media-library/manifest.json` зарегистрировано 2 208 файлов общим объёмом около 1,55 ГБ; все файлы существуют локально. Однако у схемы нет полей `license_url`, `rights_verified_at`, `rights_verified_by`, `accessed_at`, `content_hash` и реестра использований. Поэтому ни один актив нельзя считать полностью проверенным по одной записи manifest.

Особые блокеры:

- 1 555 assets помечены как `argentina.travel`, но текст `Argentina.travel / INPROTUR — указать источник на сайте` не является лицензией на коммерческое повторное использование;
- 4 local assets не имеют source URL, license и author;
- 2 Pexels assets не имеют source URL;
- 200 Wikimedia assets имеют неоднозначную лицензию `CC BY-SA / CC BY`, 176 — общего автора `Wikimedia Commons contributors`;
- у 415 assets отсутствует caption;
- 172 файла больше 2 МБ, максимальный — около 46,5 МБ;
- 176 групп имеют одинаковый hash (543 assets), а в 106 группах одинаковому файлу приписаны разные source URL.

Пока provenance не исправлен, эти записи имеют `rights_status=review_required`. Четыре local assets без происхождения — `blocked`.

## Обязательные поля

Для каждого актива: creator; source page; оригинальный URL; конкретная лицензия; license URL; attribution text; дата доступа; дата и актор проверки прав; hash; размеры; тип; caption/alt для каждой опубликованной locale; географическая сущность; все usages.

`sourceUrl` прямого файла недостаточен для Wikimedia: нужна страница файла с автором и точной лицензией. Общая строка `Wikimedia Commons contributors` не заменяет creator.

## Допустимые источники

1. Собственные фотографии — только с договором/подтверждением владельца и автором.
2. Официальные органы — только с явно разрешающими условиями повторного использования.
3. Wikimedia Commons — по лицензии конкретного файла и с полным attribution.
4. Pexels/Unsplash — по актуальным правилам платформы; для API сохраняются profile/download tracking evidence.
5. Платные библиотеки — с идентификатором приобретённой лицензии.

Публичная доступность, указание автора или фраза «официальный портал» сами по себе не дают право использования.

## Запрещено

- публиковать `review_required` или `blocked` asset;
- менять source metadata без пересчёта hash;
- приписывать один локальный файл разным исходным URL;
- использовать похожий объект вместо реального места;
- hotlink неизвестного файла;
- публиковать документальное AI-изображение без маркировки;
- показывать credit только внутри alt;
- заменять отсутствующее фото текстом `Нет фото` на индексируемой странице.

## Замена и повторное использование

Один физический asset может иметь несколько usages, но provenance один. Caption и alt принадлежат usage/locale и могут различаться. Замена файла создаёт новую версию asset и не меняет старый hash; массовая замена выполняется через usage relation и имеет rollback.

## Производительность

- hero: целевой размер до 400 КБ, отдельный LCP budget;
- content image: до 300 КБ, gallery lazy-loaded;
- исходник хранится отдельно от производных AVIF/WebP;
- width/height обязательны, ниже первого экрана — lazy;
- 172 существующих файла >2 МБ требуют обработки до повторной публикации.

## Проверка перед публикацией

`media gate` проверяет права, соответствие географии, hash/provenance conflict, alt, caption/credit, размеры, существование storage object и отсутствие запрещённого remote hotlink.
