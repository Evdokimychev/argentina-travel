# Карта пользовательских сценариев

## B2C

Выбор направления → поиск → результат → карточка → заявка → подтверждение → оплата → управление поездкой.

## Гостевая заявка

Email → нейтральный ответ → одноразовый код → 15-минутная сессия → минимальный список заявок.

## B2B

Регистрация → проверка → черновик → модерация → публикация → заявка → проведение → выплата.
