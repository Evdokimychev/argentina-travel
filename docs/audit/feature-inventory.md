# Инвентаризация функций

- Основной B2C: направления, туры, экскурсии, подбор, бронирование, оплата, кабинет.
- Информационный контур: места, карта, путеводитель, база знаний, блог, иммиграция.
- B2B: onboarding организатора, предложения, модерация, заявки, сообщения, выплаты, аналитика.
- Supporting/experimental: магазин, форум, галерея, партнёрские сервисы.
