# Управление дизайном сайта — 15 июля 2026

## Цель

Дать владельцу сайта возможность менять глобальный внешний вид из админки без правки кода и без
риска получить разрозненные цвета, случайные шрифты или сломанные мобильные состояния.

## Доступные настройки

| Группа | Варианты |
|---|---|
| Палитра | Argentina, Patagonia, Wine |
| Шрифт заголовков | фирменный Unbounded, книжная антиква, системный |
| Шапка | воздушная, компактная |
| Футер | светлый, голубой туман |
| Элементы | служебная полоса, карта, тема, подписка, маршрутный CTA |

По умолчанию используется существующая спокойная система Argentina: серо-голубые поверхности,
светлый футер, воздушная шапка и выключенная служебная полоса.

## Как это устроено

- Админка показывает живой макет шапки, страницы и футера до сохранения.
- API принимает только известные ключи и варианты.
- Нормализатор заменяет отсутствующие или неизвестные значения безопасными значениями по умолчанию.
- Настройки хранятся в существующей JSONB-записи `site_settings` с ключом `site.design`; отдельная
  миграция не требуется.
- Корневой layout один раз получает настройки и передаёт их шапке и футеру. Цвета и шрифты
  применяются через семантические токены, поэтому новые шаблоны автоматически наследуют систему.

## Почему нет произвольных HEX и CSS

Свободный ввод цвета выглядит гибким, но позволяет случайно создать нечитаемые кнопки, нарушить
контраст или превратить разные страницы в разные продукты. Пресеты дают редактору самостоятельность,
а расширение остаётся простым: дизайнер добавляет проверенную палитру в реестр, после чего она
становится доступна всем страницам.

## Системное влияние

- Турист: видит согласованную шапку, типографику и футер на публичных страницах.
- Редактор: меняет оформление и состав глобальных элементов из одного раздела.
- Организатор, CRM, бронирование и платежи: бизнес-логика и данные не меняются.
- База: используется существующий универсальный механизм глобальных настроек.

## Критерии проверки

- неизвестные варианты отклоняются нормализатором;
- значения по умолчанию визуально совпадают с текущим сайтом;
- компактная шапка резервирует правильную высоту до гидратации;
- мобильные действия имеют зону нажатия не менее 44 px;
- дополнительные палитры используют достаточно тёмные акценты на светлых поверхностях;
- при отключении каждого элемента макет не оставляет пустых блоков.
