# Поисковая видимость — Google Search Console и Яндекс.Вебмастер

## Что реализовано

В админке есть раздел **Маркетинг → Поиск и SEO**. Он показывает реальные запросы, показы, переходы, CTR, среднюю позицию, сильные страницы и запросы с самым быстрым потенциалом роста.

- Google Search Console: запросы по датам, страницам, странам и устройствам.
- Яндекс.Вебмастер: популярные запросы, показы, переходы и средние позиции.
- Ручное обновление из админки и ежедневное серверное обновление.
- Начальная карта спроса по Аргентине без выдуманных частотностей. После подключения приоритеты определяются фактическими показами сайта.
- Поисковые фразы доступны только администраторам с правом просмотра аналитики.

Секреты сохраняются в Supabase Vault, не попадают в браузерные ответы и не хранятся в общих настройках сайта. Метрики старше 400 дней автоматически удаляются.

## Подключение Google Search Console

1. Создайте сервисный аккаунт в Google Cloud и JSON-ключ для него.
2. В Search Console откройте настройки ресурса `sc-domain:goargentina.ru` и добавьте email сервисного аккаунта как пользователя с правом чтения.
3. В админке откройте **Маркетинг → Поиск и SEO → Google Search Console**.
4. Укажите `sc-domain:goargentina.ru`, вставьте содержимое JSON-ключа и сохраните подключение.
5. Нажмите **Получить свежие запросы**.

Google может не возвращать анонимизированные редкие запросы и отдаёт верхние строки в пределах внутренних лимитов Search Console. Поэтому цифры в этой панели предназначены для приоритизации, а не для бухгалтерской сверки всего органического трафика.

Официальная документация: [Search Analytics API](https://developers.google.com/webmaster-tools/v1/searchanalytics/query), [авторизация](https://developers.google.com/webmaster-tools/v1/how-tos/authorizing).

## Подключение Яндекс.Вебмастера

1. Создайте OAuth-токен Яндекса с доступом к Вебмастеру.
2. В админке откройте **Маркетинг → Поиск и SEO → Яндекс.Вебмастер**.
3. Укажите `https://www.goargentina.ru/`, вставьте токен и сохраните подключение.
4. Нажмите **Получить свежие запросы**.

Токен Яндекса действует ограниченное время; по актуальной документации Вебмастера — шесть месяцев. При истечении доступа панель не показывает техническую ошибку посетителям: администратор увидит, что подключение надо обновить.

API популярных запросов Яндекса возвращает до 3000 запросов за неделю, максимум по 500 строк за один запрос. Официальная документация: [популярные запросы](https://yandex.com/dev/webmaster/doc/ru/reference/host-search-queries-popular), [OAuth](https://yandex.com/dev/webmaster/doc/ru/tasks/how-to-get-oauth).

## Что уже не нужно настраивать повторно

Яндекс.Метрика подключена отдельно и с учётом согласия пользователя. Её счётчик измеряет поведение на сайте, а Яндекс.Вебмастер отвечает на другой вопрос: по каким поисковым фразам сайт показывался и на каких позициях. Токен Вебмастера не заменяет счётчик Метрики и не публикуется в клиентском коде.

## Рабочий цикл SEO

### Каждую неделю

1. Сначала обрабатывать запросы с показами и позицией 4–20.
2. Для страниц с высокой позицией и низким CTR улучшать заголовок и описание, не обещая того, чего нет на странице.
3. Добавлять практический ответ в первый экран, внутренние ссылки, карту, таблицу маршрута или проверенный чек-лист.
4. Проверять дату фактической верификации, автора, первичные источники и отсутствие дублей.
5. Не создавать несколько почти одинаковых страниц под перестановки слов в запросе.

### План 30 / 60 / 90 дней

- **0–30 дней:** подключить оба кабинета, собрать базовую линию, отправить актуальный sitemap, исправить каннибализацию и усилить страницы туров, Патагонии, маршрута на 14 дней и Эль-Чальтена.
- **31–60 дней:** выпускать оригинальные материалы по подтверждённым кластерам: сезоны, Игуасу, Перито-Морено, бюджет, перелёты, переезд; связывать их с турами, экскурсиями, экспертами и интерактивной картой.
- **61–90 дней:** обновлять страницы с реальными показами, тестировать сниппеты по CTR, укреплять авторство и внешние упоминания, защищать уже занятые позиции 1–3.

Высокая техническая готовность не гарантирует первое место: возраст домена, ссылки, узнаваемость и поведение аудитории накапливаются со временем. Панель устраняет работу вслепую и позволяет принимать решения по фактическим запросам именно этого сайта.
