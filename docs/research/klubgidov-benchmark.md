# UX-бенчмарк «Клуба Гидов»

Ключевые свидетельства: `research/third-party/klubgidov/argentina/mobile/above-the-fold.png` и `research/third-party/klubgidov/patagonia-tour/mobile/above-the-fold.png`.

## Информационная архитектура

Каталог страны начинается с hero-поиска и горизонтального ряда основных фильтров, затем показывает trust-маркеры, breadcrumbs, сортировку и плотную сетку карточек. Страница тура использует порядок: галерея → заголовок → рейтинг/география/длительность → доверительный блок → маршрут → проживание → условия → прибытие → важное → даты и цены → отзывы.

## Сильные решения

- Карточки заметно компактнее: визуальный образ, автор, рейтинг, география, короткое название, длительность, ближайшая дата, скидка.
- Цена и дата сформулированы прямо, без маркетплейсной терминологии.
- Trust-маркеры находятся рядом с моментом принятия решения: проверенный организатор, отсутствие комиссии, визовые подсказки.
- Маршрут и программа поданы проще и быстрее сканируются.
- Блок организатора выглядит как человеческое знакомство, а не служебная карточка продавца.
- Мобильный первый экран страницы тура не перегружен мелкими характеристиками.

## Риски и ошибки

- Две очень узкие карточки в ряд усложняют чтение длинных русских названий и дат.
- Часть фотографий получает слишком мало высоты; смысл изображения теряется.
- Trust-сообщения иногда слишком рекламные и не раскрывают источник проверки.
- Плавающие кнопки могут конфликтовать с системной safe-area и cookie banner.

## Вывод для «Пора в Аргентину»

Перенимаются компактность, прямые даты/цены, человеческий блок организатора и ранние trust-маркеры. Двухколоночная сетка на 360 px не переносится: для длинных названий Аргентины выбран один более компактный столбец.
