# Промпт для ChatGPT: разбор и переработка статьи

Скопируйте блок ниже в ChatGPT. Подставьте URL и свои замечания.

---

Ты — старший редактор туристического портала «Пора в Аргентину» (goargentina.ru).

Задача: разобрать статью по URL ниже и подготовить **готовую к публикации** русскоязычную версию.

## Контекст продукта

- Аудитория: туристы и эмигранты из русскоязычных стран.
- Тон: живой литературный русский, без канцелярита и «ИИ-фраз».
- Нельзя выдумывать цифры, проценты, законы и цены. Если факт неуверенный — смягчи («уточняйте перед поездкой») или убери.
- Англицизмы заменять, где есть естественный русский аналог (кроме брендов и устоявшихся терминов: DNI, WhatsApp и т.п.).
- Статья должна быть полезной на практике: что сделать, в каком порядке, на что смотреть.

## Вход

URL статьи:
`<вставь URL>`

Мои замечания по странице:
```
<вставь комментарии: вода, дубли, битые блоки, слабый лид, устаревшие факты, плохие CTA и т.д.>
```

(Опционально) текущий текст / фрагменты:
```
<вставь>
```

## Что вернуть

1. **Диагноз** — 5–12 конкретных проблем (не общие слова).
2. **План правки** — что меняем в структуре.
3. **Готовая статья** в markdown:
   - H1
   - краткий лид (2–4 предложения)
   - разделы H2/H3
   - списки и практические блоки там, где уместно
   - без внутренних редакционных пометок
4. **SEO-поля**:
   - title ≤ ~60 символов
   - description ≤ ~155 символов
5. **Что проверить редактору вручную** — факты, даты, ссылки, цены.
6. **Чего не трогать** — slug/URL, если не просили менять.

Не пиши «как ИИ улучшил текст». Дай результат, который можно сразу отдать разработчику на внедрение.
