## Редактирование материала

Найти материал -> «Начать редактирование» -> Основное -> Содержимое -> Медиа -> Связи -> SEO -> Публикация -> История.

Редактор показывает autosave, состояние «Сохранено», preview mobile/desktop, validation, revisions и publication checklist. Технические названия источников скрыты в «Расширенных настройках».

## Управление сайтом

Владелец может менять branding, контакты, social links, footer, navigation, CTA, home sections, featured content, support email, legal links, 404/maintenance copy, SEO defaults, map parameters и airports. Каждая операция имеет preview, validation, undo и audit entry.

## Статьи организатора

Draft -> review -> changes requested -> approved -> scheduled -> published -> archived. Организатор создаёт редакцию и отправляет на модерацию; публикация требует capability. Ошибка autosave не удаляет локальный текст.

## Карта

Редактор находит объект, меняет coordinates/importance/zoom visibility, объединяет duplicates, связывает content/tours/airport и проверяет source. Предложения организаторов проходят moderation.
