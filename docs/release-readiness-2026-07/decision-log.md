# Decision log

## D-001 — регистрация всегда начинает с роли туриста

- **Дата:** 2026-07-15
- **Причина:** `raw_user_meta_data` изменяется пользователем и не может быть источником полномочий.
- **Решение:** DB trigger и аварийное создание профиля выдают только `tourist`; admin требует явной активной записи `admin_staff`. Доверенный серверный flow может добавить organizer после регистрации.
- **Rollback:** восстановить schema backup и предыдущую функцию только при подтверждённой невозможности входа владельца; небезопасный bootstrap не возвращать.

## D-002 — вход по телефону без публичного раскрытия email

- **Дата:** 2026-07-15
- **Решение:** номер и пароль проверяются серверным endpoint; публичные lookup API не возвращают наличие аккаунта, email или роли. Регистрация стала явным действием.
- **Условие пересмотра:** заменить на настоящий SMS OTP после выбора и подключения провайдера.

## D-003 — партнёрские и незавершённые покупки называются фактическим действием

- **Дата:** 2026-07-15
- **Решение:** магазин цифровых материалов использует «Заказать PDF»/«Уточнить доступность», пока автоматическая оплата и выдача файла не подтверждены end-to-end.
- **Условие возврата CTA «Купить»:** webhook, идемпотентная выдача, письмо, возврат и reconciliation проходят staging-тест.

## D-004 — неполные локали не индексируются

- **Дата:** 2026-07-15
- **Решение:** fallback-контент доступен пользователю, но получает `noindex,follow`; hreflang публикуется только для реально опубликованных локалей.
- **Условие снятия:** редакционная проверка и публикация перевода.

## D-005 — marketing attribution требует personalization consent

- **Дата:** 2026-07-15
- **Решение:** UTM/referrer attribution не сохраняется до согласия и удаляется при отзыве. Согласие версионируется и истекает через год.

## D-006 — production-выпуск через main и Vercel с наблюдением

- **Дата:** 2026-07-15
- **Решение:** миграция обратимо проверяется до применения; код проходит quick audit, production build, browser acceptance и smoke. Деплой считается завершённым только после совпадения SHA и production smoke.
