# План безопасной миграции авторства

1. Идентифицировать владельца только по стабильному внутреннему `user_id`; email не использовать как ключ.
2. В dry-run выбрать только опубликованные редакционные материалы GoArgentina с источниками и подтверждённым review status.
3. Исключить партнёрские, пользовательские, чужие, черновые и чувствительные материалы без `expertOrLegalReview=approved`.
4. Записать до изменения `document_id`, прежнего автора, нового автора, revision id/hash и причину включения/исключения.
5. Применять пакет транзакционно после ручного утверждения CSV владельцем; создавать новую ревизию и audit event.
6. Rollback восстанавливает автора из snapshot по `document_id` и проверяет неизменность revision hash.

Автоматическое применение в production в этом аудите не выполнялось. Сначала требуется закрыть `AUTHOR-WORKFLOW-001`.
